# Personas and journeys
Reader: opens following feed, reads and replies, checks which feed is active. Trust depends on truthful ordering description.
Attention manager: visits a profile or moderation list, mutes unwanted content, reviews existing blocks and may remove them. New block option absent and mutation denied.
Guest: sees recognizable Plumblines identity, browses public content and reaches existing login flow without a rewritten authentication system.
Primary journey: open app → choose feed → read → open context → adjust existing attention settings → return to current feed.
